# 唯一灾难恢复方式

本项目唯一正式恢复流程如下：

1. 打开本项目的公开 GitHub 页面。
2. 点击 `Code`（代码菜单）。
3. 点击 `Download ZIP`（下载 ZIP）。
4. 将 ZIP 解压到一个全新的空文件夹，禁止覆盖任何旧项目目录。
5. 双击解压后根目录的“恢复生产环境.cmd”。
6. 等待脚本检查并准备工具、依赖、源码、构建资源、安全扫描和生产验证环境。
7. 阅读脚本末尾结论和 `.recovery/reports/恢复报告.txt`。

不需要 Git 客户端，不需要版本记录目录，也不需要任何旧工作区、旧客户包或本机备份源码。

## 通过标准

脚本只有在以下项目全部通过时，才报告已具备继续开发和生成生产交付物的能力：

- 公开源码清单完整。
- 秘密和隐私扫描通过。
- Python 自动测试通过。
- JavaScript 语法检查通过。
- 开发者授权器验证构建通过。
- 生产引擎验证构建通过。
- 非交付客户壳验证构建通过。
- 客户引擎中不存在私钥和授权签发模块。

恢复过程不会生成正式客户包，不会消耗正式套装编号，也不会恢复私钥或代码签名证书。

## 失败处理

失败时不要把 ZIP 覆盖到旧目录。保留当前新目录中的 `.recovery/reports/恢复报告.txt`，修复报告指出的问题后再次双击同一入口。已通过摘要检查的下载缓存可以安全复用。
