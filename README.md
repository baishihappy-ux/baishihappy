# Dingfeng Production Workspace

This public GitHub project is the authoritative disaster-recovery source for the development workspace and production-build environment.

## 唯一恢复入口

1. 在 GitHub 项目页面点击 `Code`。
2. 点击 `Download ZIP`。
3. 解压到全新的空文件夹。
4. 双击根目录“恢复生产环境.cmd”。

完整合同见 [`docs/唯一恢复方式.md`](docs/唯一恢复方式.md)。

恢复过程不需要 Git 客户端或版本记录目录。客户数据、运行状态、私钥、许可证、日志、输出和签名凭据不进入公开仓库。

For development context, read:

- `PROJECT_GROUND_TRUTH.md`
- `WORKLOG.md`
- `docs/versions/`
